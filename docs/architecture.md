# Architecture

前端只负责输入、展示和轻量格式校验；外部平台请求、帖子筛选、短链跳转检查和下载地址解析全部由 FastAPI 服务处理。

- `codex_watch`：账号配置、公开帖子采集、去重、关键词命中和可信度标记。
- `video_parser`：分享链接校验、抖音/快手/小红书 adapter 分发、统一解析结果、短期媒体令牌和不落盘流式中转。
- `clients`：外部 HTTP 客户端、逐跳重定向校验、DNS 私网拦截、超时、重试、并发限制和 User-Agent 策略。

服务端不会保存视频文件。媒体中转只接受解析接口签发的短期令牌，并执行 CDN 域名白名单、文件大小、内容类型和 Range 校验。中转连接关闭后不保留媒体字节。
